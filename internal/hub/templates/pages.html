How status works

Contact freshness is not a health guarantee. Missing measurements are unavailable, not zero. Charts, rankings and filters cover this page (up to 100 hosts); the Overview summary, host cards and Needs attention ignore the filter so it cannot hide a problem.

{{if eq .View "resources"}}

CPU cells show peak usage; comparison lines show weighted averages. Empty cells are missing data. Memory box size is host RAM, colour is usage; stale hosts are excluded.

{{end}} {{if eq .View "metrics"}}

Filesystem and ranking values are last received readings; check contact and collection times in the host details before acting.

How status works

Stat cards show the last received readings, not live values. Contact status is not application health. The disk card shows the fullest monitored mount.

{{if .Summary}}Charts show summary bucket averages; memory and disk percentages are ratios of bucket averages.{{else}}Charts show raw observations.{{end}} Missing intervals are gaps, not zeros.

Container CPU: 100% equals one core. Container memory excludes inactive file cache.
